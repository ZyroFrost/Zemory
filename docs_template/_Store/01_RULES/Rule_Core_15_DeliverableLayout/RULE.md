# Rule_Core_15_DeliverableLayout Đổi hình hài, bố cục sản phẩm giao đi thì trình trước

- Đổi hình hài · bố cục sản phẩm giao đi (layout báo cáo/dashboard · chọn biểu đồ · theme trình bày) ⇒ trình trước, không tự đổi.
- Điền số theo mẫu có sẵn ⇒ cứ làm, không cần trình.
- Cần ý tưởng biểu đồ ⇒ tham khảo skill `dataviz` rồi trình, không tự áp.
