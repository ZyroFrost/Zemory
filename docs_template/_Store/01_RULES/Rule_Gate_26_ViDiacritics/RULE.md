# Rule_Gate_26_ViDiacritics Docs viết tiếng Việt có dấu

- Docs (`docs/agent` · `docs/plan`) và thân `SKILL.md` viết tiếng Việt có dấu.
- Nhóm ngôn ngữ (`Rule_Gate_26_ViDiacritics` · `Rule_Core_66_KebabNames` · `Rule_Gate_27_SpecVoice` · `Rule_Core_29_CodeEnglish` · `Rule_Gate_30_AsciiNames` · `Rule_Core_31_TextCorrect`) là mặc định của bộ chuẩn. Bỏ hay nới vế nào ⇒ ghi quyết định vào `01_CONSTITUTION` (giữ vế nào, bỏ vế nào, vì sao). Agent không tự nới, không tự siết; chưa có quyết định ⇒ theo mặc định.
- Vế giữ kể cả khi nới hết: không viết tiếng Việt mất dấu — không dùng dấu thì viết tiếng Anh.
- Phép kiểm: cổng `guard`.
