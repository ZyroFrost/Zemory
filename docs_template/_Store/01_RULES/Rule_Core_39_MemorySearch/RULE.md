# Rule_Core_39_MemorySearch Tra Global Memory cho việc ở phiên khác

- Cần biết một việc · lỗi · quyết định đã xảy ra ở phiên khác ⇒ tra `zemory memory search "<q>" [--all]`.
- Tra đúng câu hỏi đang cần trả lời, không tra bừa.
