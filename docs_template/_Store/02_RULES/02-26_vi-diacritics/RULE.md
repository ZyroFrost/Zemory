# 02-26 Docs viết tiếng Việt có dấu

- Docs (`docs/agent` · `docs/plan`) và thân `SKILL.md` viết tiếng Việt có dấu.
- Nhóm ngôn ngữ (`02-26` · `02-66` · `02-27` · `02-29` · `02-30` · `02-31`) là mặc định của bộ chuẩn. Bỏ hay nới vế nào ⇒ ghi quyết định vào `01_CONSTITUTION` (giữ vế nào, bỏ vế nào, vì sao). Agent không tự nới, không tự siết; chưa có quyết định ⇒ theo mặc định.
- Vế giữ kể cả khi nới hết: không viết tiếng Việt mất dấu — không dùng dấu thì viết tiếng Anh.
- Phép kiểm: cổng `guard`.
