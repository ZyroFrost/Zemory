# Rule_Keys_08_ClarifyFirst Yêu cầu chưa rõ thì làm rõ trước khi làm

- Tự kích, không chờ lời gọi.
- Kích khi: đa nghĩa · thuật ngữ nhiều cách hiểu · thiếu dữ kiện · phạm vi chưa xác định · giả định ngầm · hai yêu cầu mâu thuẫn · trước thao tác khó đảo.
- Chỉ áp khi đầu vào chưa đủ để làm đúng.
- Hành vi: dừng, đọc những gì đọc được, hỏi mỗi lần một câu kèm đề xuất; đủ rõ mới làm.
- Không tự chọn cách hiểu rộng nhất.
- Kích hoạt thủ công khi lời gọi chứa "grill".
- Quy trình: `.claude/skills/harness-grill/SKILL.md`.
